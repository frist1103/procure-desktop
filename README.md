# ระบบจัดซื้อพัสดุและครุภัณฑ์ (procure-desktop)

ระบบงานพัสดุของโรงเรียนห้องสอนศึกษา ในพระอุปถัมภ์ฯ — กรอกงานจัดซื้อแบบทีละขั้น ออกเลขที่ราชการ และออกเอกสาร Word (.docx) ตามแบบฟอร์มราชการ

## โครงสร้าง
| โฟลเดอร์ | คืออะไร |
|---|---|
| `gas/` | โค้ด Google Apps Script (เว็บแอพ + ฐานข้อมูล Google Sheets) — ตรงกับที่ใช้งานจริง รุ่น 0.3.3 |
| `test/` | ชุดทดสอบ (จำลอง Apps Script ใน Node.js) ใช้ข้อมูลสมมุติใน `test/seed.json` |
| `desktop/` | (เฟส D — กำลังทำ) โปรแกรมติดตั้งบน Windows (Electron) ประมวลผลในเครื่อง ซิงก์กับ Google Sheet |

## ข้อมูลส่วนตัว
repo นี้เป็นสาธารณะ จึง**ไม่มี**ข้อมูลจริง: รายชื่อ/อีเมลบุคลากรใน `test/seed.json` เป็นชื่อสมมุติ, เทมเพลต .docx และฐานข้อมูลจริงอยู่ใน Google Drive ของโรงเรียน (เข้าถึงได้เฉพาะบัญชีที่ได้รับสิทธิ์)

## ทดสอบ
```
npm test                 # ทดสอบภาษาไทย/จำนวนเงิน และ API แบบจำลอง
npm run test:full        # ต้องมีโฟลเดอร์ templates/ (คัดลอกเทมเพลตจาก Drive มาวาง)
```
